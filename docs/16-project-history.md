# Project History

This file records how the project direction evolved.

## Original Direction

The original ambition was to build something like:

- a research lab for agents
- many agents coordinated by a main brain
- persistent memory and orchestration
- nonstop experimentation and discovery

The early thinking was about:

- agent orchestration
- research loops
- memory systems
- long-horizon autonomous work

## Why The Direction Changed

While discussing orchestration, memory, repo recall, and machine context, a more immediate product pain surfaced:

- people constantly know something exists on their computer but cannot find it

This pain was stronger, more universal, and easier to productize than a general autonomous research lab.

Examples that triggered the pivot:

- "Where the hell is that file?"
- "Where is that repo?"
- "Find the image I took in Colorado."
- "What was I working on before this?"

## The Pivot

The project pivoted from:

- autonomous research lab

to:

- Machine Memory

Machine Memory is the new primary product direction.

## What Was Preserved From The Original Vision

The original vision was not discarded entirely. Several ideas survived and now sit deeper in the roadmap:

- persistent memory
- machine context for AI
- long-term retrieval
- timeline reconstruction
- eventually, deep Linux system-level observability

So the project changed shape, but it did not abandon the ambition.

## Current Interpretation

The current strategy is:

1. build a painful, obvious product first
2. make machine search and recall real
3. expand into work resurrection and long-term memory
4. expose machine memory to AI agents through MCP or API
5. deepen into Linux-native observability later

## Long-Term End Goal

The long-term end goal is still much bigger than file search.

It points toward:

- a memory layer for a machine
- a private answer engine for a digital life
- eventually, deeper Linux-native, near-kernel or system-level observability

That means the current wedge is not the whole vision.
It is the first practical and shippable slice of that larger system.

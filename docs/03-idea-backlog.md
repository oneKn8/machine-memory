# Idea Backlog

This file captures the broader idea space discovered so far.

## Core Product Family

### Machine Memory

The main product direction.

- local semantic search
- machine recall
- project resurrection
- memory for humans and AI agents

### Machine SEO / AEO

A useful metaphor:

- SEO for the web helps information get found
- Machine SEO helps information on a local machine become findable and answerable

This is not the final product name, but it is a strong framing.

## Related Product Wedges

### Repo Locator

Find local repos by fuzzy memory:

- repo name
- GitHub remote
- topic
- last touched
- README/package metadata

### Work Resurrection

Answer:

- "What was I doing last week?"
- "What repo did I touch before X?"

### Photo And Screenshot Recall

Find images by:

- place
- person
- OCR text
- approximate time
- event cluster

### Local Repo Brain

Machine-aware context layer for coding agents:

- repos
- paths
- commands
- notes
- related files

### Command Memory

Recover useful commands by:

- repo
- task
- timeframe
- error pattern

## Near-Term Product Positioning Options

- Search your computer by memory, not by filename.
- Ask your machine where things are.
- A private answer engine for your machine.
- Machine memory for developers.

## Long-Term Expansion

If the wedge works, the platform can expand into:

- daily logs
- behavioral memory
- phone logs and exports
- timeline reconstruction
- local knowledge graph
- system-level event indexing
- shared memory for agents

# Demo Queries

These queries should make the product instantly understandable.

## File And Repo Queries

- Where is gitonsteroid?
- Find the repo tied to this GitHub remote.
- Show me the repo I was editing before ruflo.
- Find the PDF about quantization.
- Find the movie file I downloaded but never opened.

## Image Queries

- Find the image I took in Colorado.
- Show me my sister's image.
- Find the photo of my mother from Christmas.
- Show me the screenshot I took while debugging MCP.

## Work Queries

- What was I working on last Tuesday night?
- Show files related to the startup idea.
- What project is this document connected to?
- Show me everything related to the lab idea.

## Trust-Building Query Requirements

For each answer, the system should show:

- top matches
- confidence or rationale
- file path
- supporting metadata
- optional related items

The result should feel grounded, not dreamy.
